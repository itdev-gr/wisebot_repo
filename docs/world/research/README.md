# WiseBot World — το ερευνητικό στρώμα

Γραμμένο 11 Σεπτεμβρίου 2026. Αυτός ο φάκελος **δεν περιέχει κώδικα και δεν περιέχει
περιεχόμενο της εφαρμογής**. Περιέχει τις μετρήσεις και τις πηγές πάνω στις οποίες
δουλεύουν τα δύο sessions του [SESSION-SPLIT.md](../SESSION-SPLIT.md).

Κανένα αρχείο εδώ δεν ανήκει στο Session A ή στο Session B, και τίποτα εδώ δεν
γράφεται ποτέ μέσα στο `data/`, στο `components/` ή στο `scripts/`. Γι' αυτό μπορεί
να δουλεύεται παράλληλα χωρίς σύγκρουση.

| Κείμενο | Τι απαντά |
| --- | --- |
| [01-coordinate-audit.md](01-coordinate-audit.md) | Γιατί τα pins δείχνουν λάθος και πού είναι στ' αλήθεια οι πόρτες |
| [02-museums.md](02-museums.md) | Ποια μουσεία αξίζουν την ώρα ενός παιδιού, με Wikidata ids |
| [03-languages.md](03-languages.md) | Πόσες γλώσσες, με ποια σειρά, και πότε εμφανίζεται κουμπί |
| [04-how-many-cities.md](04-how-many-cities.md) | Τι κοστίζει μία πόλη, άρα πόσες αντέχουμε |

| [06-doors-worklist.md](06-doors-worklist.md) | Οι 35 πόρτες που λείπουν, με σειρά προτεραιότητας και επιτρεπόμενες πηγές |

Δεδομένα: [entrances.json](entrances.json) οι μετρημένες πόρτες,
[museums.json](museums.json) και [greek-museums.json](greek-museums.json) τα μουσεία,
[doors-worklist.json](doors-worklist.json) οι διευθύνσεις και οι επίσημες σελίδες. Τα

## Τα τρία ευρήματα που αλλάζουν δουλειά

1. **Καμία «είσοδος» δεν είναι είσοδος.** Είκοσι επτά μέρη σε τρεις πόλεις δηλώνουν
   πόρτα, κανένα δεν κουβαλά συντεταγμένη πόρτας. Το Παναθηναϊκό Στάδιο αστοχεί κατά
   127 μέτρα, η Ρωμαϊκή Αγορά της Θεσσαλονίκης κατά 98, η αγορά Bolhão κατά 62. Ο
   έλεγχος στον resolver που υποτίθεται ότι το πιάνει αυτό δεν μπορούσε ποτέ να
   πυροδοτηθεί. **Διορθώθηκε αυθημερόν από το Session A**· μένουν οι 35 πόρτες να
   μετρηθούν.
2. **Οι έξι γλώσσες είναι δύο.** Μηδέν κείμενα σε γερμανικά, γαλλικά, ισπανικά και
   ιταλικά. Και τα πορτογαλικά, η γλώσσα των δύο από τις τρεις πιλοτικές πόλεις,
   λείπουν εντελώς από τη λίστα.
3. **Μία πόλη κοστίζει 467 κείμενα και 8.000 λέξεις ανά γλώσσα.** Οι σαράντα πέντε
   πόλεις σε έξι γλώσσες είναι πάνω από δύο εκατομμύρια λέξεις.

## Τι χρειάζεται απόφαση από τον ιδιοκτήτη

1. Το παιδί στέκεται μπροστά στο έκθεμα ή ταξιδεύει από τον καναπέ; Καθορίζει το
   Museum Mode, το Offline, τα photo challenges και το αν χρειαζόμαστε τοποθεσία.
2. Πόσα μέρη ανά πόλη; Η Αθήνα έχει 18. Δεκαπέντε είναι ένα απόγευμα, τριάντα είναι
   μήνας.
3. Τι σημαίνει «Mastered» στο διαβατήριο;
4. Ο Κόσμος σε έξι γλώσσες μέσα σε εφαρμογή δύο γλωσσών, ή ευθυγράμμιση;
